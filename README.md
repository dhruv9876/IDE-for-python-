# Python Code Editor

A lightweight desktop-based Python IDE built using Python and Tkinter. The application provides an intuitive environment for writing, editing, saving, and executing Python programs while offering syntax highlighting, integrated output display, keyboard shortcuts, and file management.

Designed for students, beginners, and developers, the editor delivers a focused coding experience without the complexity of larger Integrated Development Environments (IDEs).

---

## Features

- Open, Save, and Save As support
- Python code execution
- Integrated output console
- Syntax highlighting for Python keywords
- Built-in function highlighting
- String and comment highlighting
- Keyboard shortcuts (Ctrl+S, Ctrl+O, F5)
- Error handling and execution feedback
- Dynamic file tracking
- Object-oriented architecture

## How It Works

The application provides a text editor where users can write Python code. When the Run option is selected, the current script is executed using Python's subprocess module. Standard output and error messages are captured and displayed within the integrated output console, allowing users to test and debug Python programs without leaving the editor.
